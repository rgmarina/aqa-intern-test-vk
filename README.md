## Решение тестового задания

В рамках задания исправлены существующие автотесты виджета поддержки Учи.ру и реализован один дополнительный тест.

### Исправленные ошибки

**1. Ошибка получения популярных статей**

Метод `getPopularArticles()` возвращал пустой массив, поскольку `locator.all()` не ожидал загрузки элементов. Добавлено ожидание видимости первой статьи перед получением списка.

**2. Ошибка выбора кнопки «Написать нам»**

Первоначальный селектор `[class^=btn]` находил несколько элементов и приводил к `strict mode violation`. Он заменён на точный селектор `[data-test="button_feedback_form"]`.

**3. Улучшена синхронизация тестов**

Добавлено ожидание отображения виджета после открытия. Проверка заголовка переведена на `toHaveText()`, а переход на страницу выполняется с `waitUntil: 'domcontentloaded'`.

### Дополнительный тест

Реализован `displays popular articles`.

Он проверяет наличие популярных статей в виджете, видимость первой статьи и наличие у неё непустого заголовка.

### Запуск

```bash
npm ci
npx playwright install chromium
npx playwright test
```
